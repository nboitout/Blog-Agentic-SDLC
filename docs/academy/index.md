# Claude SDK & Certification Prep

A study track built on top of this course's own material, mapped to the public domain
blueprints for Anthropic's Claude Certified exams — Associate, Developer, and Architect.
**This is an independent resource, not affiliated with or endorsed by Anthropic** — our own
reading of the published exam domains, built to teach the underlying engineering discipline,
not just the vocabulary you'd need to pass a test.

Each module below opens as its own interactive page — a click-through deck or a searchable
reference, depending on what the topic calls for.
